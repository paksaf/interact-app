How to install (any Android device)

  1. Open this page on the device and tap a green download button (or send the copied link via WhatsApp/SMS and open it there).
  2. When the download finishes, tap the APK file in your notifications or Files app.
  3. If asked, allow "Install unknown apps" for your browser — Settings → tap Allow, then go back. (One-time step; these are official INTERACT builds, verified by the SHA-256 shown in latest.json.)
  4. Tap Install. On Xiaomi/Redmi also enable Install via USB / unknown sources under Security settings if blocked.
  5. Car head units: if there's no browser, download on a phone, copy the APK to a USB stick, and open it with the unit's file manager.

Updating over an existing install keeps your account and data. If Android says "App not installed – version conflict", uninstall the old copy first (you will need to sign in again).
